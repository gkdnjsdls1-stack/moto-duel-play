# 오토바이 대결

브라우저에서 바로 하는 2인 오토바이 레이싱. 조작은 브레이크·엑셀·운전대 셋뿐이고,
한 판은 2바퀴 약 1분이다. 설치할 것도, 로그인도 없다.

**▶ https://gkdnjsdls1-stack.github.io/moto-duel-play/**

가로로 눕혀서 연다. 「홈 화면에 추가」를 해두면 앱처럼 열린다.

- **한 기기로 둘이** — 화면 좌우 반반
- **혼자 연습** — 기록 도전
- **토너먼트** — 준결승 2판 → 3·4위전 → 결승

기기 2대를 연결하는 모드는 이 주소에서는 동작하지 않는다.

`index.html` 한 파일에 전부 들어 있다 (CSS·HTML·게임엔진). 의존성 없음.
